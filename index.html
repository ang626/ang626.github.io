ABOUT ME

하나의 기능이 완성되기까지,

Java와 Spring Boot를 기반으로 API와 데이터베이스를 구현하고, Vue.js를 활용한 프론트엔드와 연결해 웹 서비스가 동작하는 과정을 경험했습니다.

개인 프로젝트는 문제와 기능을 정리하는 단계부터 화면·서버 구현, 동작 확인과 수정까지 혼자 진행했습니다. 개발 과정에서 AI를 참고하기도 했으며, 제안된 코드를 이해하고 프로젝트에 맞게 검토·수정하는 데 집중했습니다.

기능을 구현할 때는 요청이 전달되는 과정부터 데이터가 저장되고 조회되는 과정까지 확인하여, 각 단계가 의도한 대로 동작하는지 검토합니다.
